# بوت حسابات MAZBOOT 🤖📒

بوت تليجرام بتكتبله المصروف أو الدخل زي ما بتتكلم، وهو يسجله في شيت حسابات MAZBOOT بعد ما تأكد.

```
إنت:  جبت فراخ ب1200 ورز ب300
البوت: 📝 هسجّل كده:
       1) 🥩 خامات وبضاعة — 1,200 ج   (فراخ · 22/11 · عمر · كاش الشركة)
       2) 🥩 خامات وبضاعة — 300 ج     (رز · 22/11 · عمر · كاش الشركة)
       الإجمالي: 1,500 ج
       [✅ سجّل] [❌ إلغاء] [✏️ فئة 1] [✏️ فئة 2] [💳 طريقة الدفع]
إنت:  ✅
البوت: ✅ اتسجل (#12، #13)
       🟠 خامات وبضاعة قرّبت تخلص: 8,700 ج من 10,520 ج (83%) — باقي 1,820 ج
```

## إزاي الشغل ماشي

```
تليجرام ──► البوت (Python) ──► Google Sheet «MAZBOOT Finance»
                                   ├─ الحركات   ◄── البوت بيكتب هنا بس
                                   └─ باقي التابات معادلات بتتحدث لوحدها
```

- البوت **بيضيف سطور في تاب «الحركات» بس**. الميزانية وقائمة الدخل والكاش والشركاء والداشبورد كلها معادلات بتتحدث لوحدها.
- البوت بيفهم الرسالة بطريقتين: **بالقواعد** (بيشتغل على طول ومن غير فلوس)، أو **بالذكاء الاصطناعي** لو حطيت `ANTHROPIC_API_KEY`، ولو الـ AI وقع بيرجع للقواعد.
- الفئات والكلمات اللي البوت بيفهمها جاية من **تاب الإعدادات**. يعني لو ضفت كلمة زي «سمسم» في كلمات فئة «خامات وبضاعة» وبعتّ `/reload`، البوت هيبدأ يفهمها.

## التشغيل خطوة بخطوة (حوالي 20 دقيقة)

### 1) الشيت
الشيت اترفع على الـ Google Drive بتاعك باسم **MAZBOOT Finance**:
https://docs.google.com/spreadsheets/d/187zDHPwgRyqN2EA-gNb4dLpJSovMGzmeP_vVZws0ahs/edit

الـ ID بتاعه متحط جاهز في `.env.example`.

### 2) Service Account (عشان البوت يقدر يكتب في الشيت)
1. افتح https://console.cloud.google.com واعمل Project جديد (مثلاً `mazboot`).
2. من **APIs & Services → Library** فعّل **Google Sheets API** و**Google Drive API** (الـ Drive مطلوب لأمر `/export`).
3. من **IAM & Admin → Service Accounts** اعمل Service Account، وبعدين **Keys → Add key → JSON**. هينزل ملف، سمّيه `service_account.json` وحطه جنب `main.py`.
4. افتح الملف وانسخ الـ `client_email` (شكله `...@....iam.gserviceaccount.com`).
5. افتح الشيت ← **Share** ← حط الإيميل ده بصلاحية **Editor**.

> ⚠️ ملف `service_account.json` ده زي الباسورد بالظبط: متحطوش على GitHub (موجود في `.gitignore`).

### 3) البوت على تليجرام
1. كلم [@BotFather](https://t.me/BotFather) وابعتله `/newbot`، واختار اسم زي `MAZBOOT Finance` ويوزر زي `mazboot_finance_bot`.
2. خد الـ token.
3. (اختياري) ابعت لـ BotFather `/setprivacy` واختار **Disable** لو هتحطوه في جروب الشركاء.

### 4) الإعدادات
```bash
cp .env.example .env
# افتح .env وحط TELEGRAM_BOT_TOKEN
```
`ALLOWED_USERS` = الـ ID بتاع كل واحد فيكم ومعاه اسمه. **الاسم لازم يكون مكتوب زي ما هو في تاب الإعدادات بالظبط** (عمر / أحمد / أسامة).
لو مش عارف الـ IDs: شغّل البوت الأول بالـ ID بتاعك بس، وخلي كل واحد يبعتله أي رسالة، هيرد عليه بالـ ID بتاعه.

### 5) التشغيل على اللابتوب (للتجربة)
```bash
python -m venv .venv && source .venv/bin/activate      # على Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### 6) التشغيل 24 ساعة
البوت شغال polling، يعني مش محتاج دومين ولا HTTPS.

**على VPS بـ Docker:**
```bash
docker compose up -d --build
docker compose logs -f
```

**على Railway / Render (من غير سيرفر):** ارفع الفولدر، وحط المتغيرات اللي في `.env` في Environment Variables. وبدل ملف `service_account.json` الصق محتوى الـ JSON كله في `GOOGLE_CREDENTIALS_JSON`. نوع السيرفس يكون **Worker** مش Web.

## الاستخدام

| ابعت | هيتسجل |
|---|---|
| `صرفت 5000 على البضاعة` | خامات وبضاعة · 5,000 |
| `جبت فراخ ب1200 ورز ب300` | سطرين خامات |
| `صرفت 5000 على البضاعة و 300 نت` | خامات 5,000 + إنترنت 300 |
| `2 كيلو فراخ ب 460` | خامات 460 · الكمية 2 |
| `بعنا ب 3500 في 15 اوردر` | مبيعات 3,500 · 15 أوردر |
| `أسامة حط 50000 رأس مال` | رأس مال · الشخص أسامة |
| `دفعت النت 300 من جيبي امبارح` | إنترنت · من جيبه · تاريخ امبارح |
| `اشتريت ثلاجة ب 25 الف` | معدات وأدوات · 25,000 |
| `الف ونص كهربا` | كهرباء ومياه وغاز · 1,500 |
| `15/11 بنزين توصيل 120 فودافون كاش` | توصيل · 15 نوفمبر · فودافون كاش |
| `سحبت 2000` | سحب شريك |

لو البوت معرفش الفئة هيطلعلك زراير تختار منها. ولو الفئة غلط دوس **✏️ غيّر الفئة** قبل ما تأكد.

**الأوامر:** `/month` · `/month 2026-12` · `/budget` · `/today` · `/last` · `/last 20` · `/cash` · `/undo` · `/export` · `/cats` · `/reload` · `/id` · `/help`

### المبيعات
سجّلوا المبيعات كل يوم أو كل أسبوع **ومعاها عدد الأوردرات** (`بعنا ب 3500 في 15 اوردر`)، عشان متوسط الأوردر ونقطة التعادل يطلعوا صح.

### «من جيبي»
لو حد فيكم دفع من فلوسه الشخصية قول «من جيبي». المصروف هيتحسب على الشركة، والمبلغ هيتسجل إنه **مستحق له** في تاب الشركاء، والكاش بتاع الشركة مش هيقل. ولما ترجعوله فلوسه سجلوها «سحب شريك».

## قواعد مهمة عشان الشيت ميبوظش
- **متغيرش أسماء التابات ومتحركش الجداول** (الإعدادات، الحركات، الميزانية). البوت بيدور عليهم في أماكن ثابتة (`mazboot_bot/layout.py`).
- تقدر تكتب في «الحركات» بإيدك عادي، وتقدر تمسح أي سطر غلط.
- عشان تضيف فئة جديدة اكتبها في صف فاضي في جدول الفئات في الإعدادات، وبعدين ابعت للبوت `/reload`.
- كل تعديل في الأرقام (أسعار، ميزانية، نسب الشركاء) بيتعمل في الخانات **الصفرا** بس.

## وضع Excel المحلي (من غير Google)
`STORAGE=excel` و`EXCEL_PATH=MAZBOOT_Finance.xlsx`، والبوت هيكتب في الملف على طول. **اقفل الملف في إكسيل وإنت بتسجل من البوت**، ولو كان مفتوح البوت هيقولك. تنبيهات الميزانية في الوضع ده محتاجة LibreOffice متسطب، أو إنك تفتح الملف في إكسيل وتحفظه مرة.
